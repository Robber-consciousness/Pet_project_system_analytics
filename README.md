# Pet_project_system_analytics

Проект, создан для базового понимания уровня моих компетенций по бизнес-анализу и системному анализу на начало 2023 года.

Системный анализ & Бизнес-анализ.
Описание: Данная тема подразумевает создание системы, которая позволяет собирать, хранить и управлять данными, связанными с промышленными комплексами, а также обеспечивать удобство и качество обслуживания данной системы.
Компоненты системы: Apache Superset, MySQL, IoT, MES, SCADA, PLC, Sensors.

Состав проекта:
1. Цели проекта
2. Концепция и границы
3. Функциональные и нефункциональные требования
4. Сценарии и контекстная диаграмма 
5. Бизнес-процессы
6. Взаимодействие компонентов системы
7. Проектирование API для фронтенда
7.1 Макеты
7.2 Спецификация в формате openAPI
8. Проектирование асинхронного взаимодействия
9. Проектирование моделей данных
